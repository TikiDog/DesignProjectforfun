# How to View Your Portfolio

## Your Portfolio Files:
- `index.html` - Main portfolio page
- `style.css` - Styling
- `script.js` - Interactive features

## Easy Viewing Options:

### Option 1: View on GitHub
1. Go to: https://github.com/TikiDog/DesignProjectforfun
2. Switch to branch: `claude/pdf-to-html-portfolio-Stm1i`
3. Click on `index.html` to see the code

### Option 2: Download and Open Locally
1. Download the repository as a ZIP file from GitHub
2. Extract the ZIP file to a folder on your computer
3. Navigate to the extracted folder
4. Find `index.html`
5. Double-click `index.html` - it will open in your web browser!

### Option 3: View Using HTML Preview
1. Go to the GitHub repository
2. Navigate to `index.html` on the branch `claude/pdf-to-html-portfolio-Stm1i`
3. Copy the URL
4. Visit: https://htmlpreview.github.io/
5. Paste the URL and click preview

### Option 4: Use Raw GitHub Content
Visit this URL (replace with your actual GitHub path):
```
https://raw.githack.com/TikiDog/DesignProjectforfun/claude/pdf-to-html-portfolio-Stm1i/index.html
```
