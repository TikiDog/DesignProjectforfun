Workflow Manager

Organize your tasks with drag-and-drop and color coding

Color:

How to use:

  • Add tasks: Type in the input field, select a color, and click "Add Task"
  • Sort tasks: Drag and drop tasks to reorder them
  • Change color: Click on a task's color circle to change its category
  • Delete tasks: Click the × button on any task
  • Filter: Use the filter buttons to view tasks by category
