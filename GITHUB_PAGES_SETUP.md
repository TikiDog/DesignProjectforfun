# 🌐 How to Enable GitHub Pages (View Your Portfolio in Browser)

GitHub Pages lets you view your portfolio directly in a web browser without downloading! Follow these simple steps:

---

## ⚙️ **Step 1: Go to Repository Settings**

1. Open your repository: https://github.com/TikiDog/DesignProjectforfun
2. Click the **⚙️ Settings** tab (top right of the repository page)

---

## 📄 **Step 2: Navigate to Pages Settings**

1. In the left sidebar, scroll down and click **"Pages"** (under "Code and automation")
2. You'll see the GitHub Pages configuration panel

---

## 🔧 **Step 3: Configure GitHub Pages**

Under **"Build and deployment"**:

1. **Source**: Select **"Deploy from a branch"**
2. **Branch**:
   - Click the dropdown that says "None"
   - Select **`claude/pdf-to-html-portfolio-Stm1i`**
   - Keep the folder as **`/ (root)`**
3. Click **"Save"**

---

## ⏳ **Step 4: Wait for Deployment (1-2 minutes)**

GitHub will build your site. You'll see a message:
> "Your site is ready to be published at..."

Refresh the page after a minute or two.

---

## 🎉 **Step 5: Get Your Live URL**

Once deployed, you'll see:
> "Your site is live at `https://tikidog.github.io/DesignProjectforfun/`"

**That's your portfolio URL!** 🎊

## ⚠️ **Troubleshooting**

### "I don't see the Pages option in Settings"
- Make sure your repository is **public** (GitHub Pages requires public repos for free accounts)
- If private, you'll need GitHub Pro

### "The site shows a 404 error"
- Wait 2-3 minutes after enabling Pages
- Clear your browser cache and try again
- Make sure `index.html` is in the root of your branch

### "I see old content"
- GitHub Pages can cache for a few minutes
- Try opening in incognito/private browsing mode
- Wait 5 minutes and refresh

### "Images/PDFs aren't loading"
- Check file paths are correct (case-sensitive!)
- Make sure files were uploaded to the correct folders
- Verify files are in the same branch as your HTML
